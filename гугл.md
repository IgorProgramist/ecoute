Так, можеш повністю зробити це локально — без завантаження книги на сторонні сайти. Для твого випадку найкраща схема: **PDF/DOCX/EPUB → вилучення тексту → поділ на фрагменти → український TTS → MP3/M4B**.

## Готові репозиторії

### 1. ebook2audiobookpiper-tts

[GitHub: DrewThomasson/ebook2audiobookpiper-tts](https://github.com/DrewThomasson/ebook2audiobookpiper-tts)

Це найближче до готового рішення:

- приймає електронні книги;
- використовує Calibre для конвертації;
- генерує аудіо через Piper;
- має вебінтерфейс Gradio;
- підтримує українську;
- може запускатися через Docker;
- має офлайн-режим із моделями голосів. [github](https://github.com/DrewThomasson/ebook2audiobookpiper-tts)

Швидкий запуск через Docker:

```bash
docker run -it --rm \
  -p 7860:7860 \
  --platform=linux/amd64 \
  athomasson2/ebook2audiobookpiper-tts:latest_large
```

Після запуску відкрий у браузері:

```text
http://localhost:7860
```

Якщо маєш NVIDIA GPU:

```bash
docker run -it --rm --gpus all \
  -p 7860:7860 \
  --platform=linux/amd64 \
  registry.hf.space/drewthomasson-ebook2audiobookpiper-tts-gpu:latest \
  python app.py
```

Для першої перевірки я б почав саме з цього репозиторію.

### 2. OB_AI_TTS

[GitHub: Engineer2031/OB_AI_TTS](https://github.com/Engineer2031/OB_AI_TTS)

Це офлайн-програма саме для озвучення українського тексту через Piper. Вона може бути простішою за повноцінний генератор аудіокниг, якщо ти хочеш озвучувати TXT або вже очищений текст. [github](https://github.com/Engineer2031/OB_AI_TTS)

### 3. Piper

[GitHub: OHF-Voice/piper1-gpl](https://github.com/OHF-Voice/piper1-gpl)

Piper — швидкий локальний TTS-движок. Старий репозиторій `rhasspy/piper` архівований, а розробку перенесено до `OHF-Voice/piper1-gpl`. [github](https://github.com/rhasspy/piper)

Для української доступні голоси:

- `uk_UA-lada-x_low`;
- `uk_UA-ukrainian_tts-medium`.

Українські моделі Piper також доступні через документацію та сховище голосів. [tderflinger.github](https://tderflinger.github.io/piper-docs/about/voices/download/)

## Що вибрати

| Варіант | Складність | Для чого підходить |
|---|---:|---|
| `ebook2audiobookpiper-tts` | Низька | Книга або великий документ → аудіокнига |
| `OB_AI_TTS` | Низька/середня | Просте офлайн-озвучення українського тексту |

Coqui TTS потужніший і має багато попередньо навчених моделей, але для стабільної української офлайн-озвучки я спочатку перевірив би Piper. [pypi](https://pypi.org/project/coqui-tts/)

## Чи може допомогти Claude Code

Так. Claude Code може:

- клонувати репозиторій;
- прочитати README;
- створити Docker-конфігурацію;
- додати підтримку PDF, DOCX і EPUB;
- написати скрипт очищення тексту;
- розбивати текст на частини;
- запускати Piper;
- об’єднувати MP3 у M4B;
- додати прогрес, логування та повторний запуск після помилки;
- написати тести для всього pipeline.

Але Claude Code не замінює локальні моделі: він генерує код і запускає команди, а саму озвучку виконуватиме Piper або інший TTS-движок.

## Якщо хочеш власний Python-проєкт

Можна попросити Claude Code створити pipeline з такою структурою:

```text
document-to-audiobook/
├── input/
├── output/
├── models/
├── src/
│   ├── extract_text.py
│   ├── clean_text.py
│   ├── split_text.py
│   ├── synthesize.py
│   └── merge_audio.py
├── tests/
├── requirements.txt
└── README.md
```

Базовий workflow:

```text
document
  ↓
extract text
  ↓
remove headers, footers and page numbers
  ↓
split by chapters and sentences
  ↓
Piper Ukrainian voice
  ↓
WAV files
  ↓
MP3 or M4B audiobook
```

Для великих файлів обов’язково попроси Claude Code додати:

- збереження прогресу;
- пропуск уже готових частин;
- журнал помилок;
- автоматичне повторення невдалих фрагментів;
- нормалізацію гучності;
- обмеження довжини фрагмента;
- метадані книги й розділів;
- коректне оброблення сканованих PDF через OCR.
